# Optional: Gemini prompts for photo-style blog covers

The blog already has branded cover images in `assets/blog/cover-<slug>.jpg`.
If you prefer photo-style or illustrated covers, generate one with Gemini using the prompts below,
export it at **1200 × 630 px (JPG)**, and save it with the **same file name** to replace the current cover.
No code changes are needed.

Shared style (add to every prompt):
> Wide 1200x630 blog cover, dark navy background with subtle indigo and teal glow, modern minimal
> tech illustration, clean flat 3D style, soft lighting, plenty of empty space on the left for a title,
> no text, no logos, no watermarks.
